# 개인정보처리방침

골고루(GOLGORU, 이하 "앱")는 사용자의 자산 데이터를 앱 제공자의 서버에 저장하지 않습니다.
이 문서는 앱이 어떤 정보를 다루고, 어디에 보관하며, 외부로 무엇을 보내는지 설명합니다.

> 최종 수정일: 2026-09-26

## 앱이 다루는 정보

### 자산 정보

계좌명, 보유 종목, 수량, 평균 단가, 현금 잔액, 목표 비중.

사용자가 고른 방식에 따라 아래 중 한 곳에 저장됩니다.

| 시작 방식 | 저장 위치 | 지원 기기 |
| --- | --- | --- |
| 둘러보기 | 저장하지 않음 (예시 데이터) | 전체 |
| 앱에 직접 입력 | 사용자 기기 내부 저장소 (Apple 기기는 본인 iCloud에도 동기화, Android는 기기 간 공유를 켠 경우 본인 Google 드라이브) | 전체 |
| Google Sheets 연동 (1.0까지) | 사용자 본인의 Google 스프레드시트 | iPhone · iPad · Mac |
| 짜보기 구성안 (1.3.0부터) | 사용자 기기 내부 저장소 (Apple 기기는 본인 iCloud에도 미러링) | 전체 |

세 경우 모두 **앱 제공자의 서버에는 저장되지 않습니다.**

기기 내부 저장소는 플랫폼이 제공하는 앱 전용 영역입니다 — Apple 기기는 앱 샌드박스,
Android는 앱 전용 저장소(다른 앱이 읽을 수 없고, 기기 백업에도 포함되지 않습니다).

Apple 기기에서 "앱에 직접 입력"으로 넣은 원장은 아이폰·아이패드에서 함께 보기 위해
**사용자 본인의 iCloud**에도 동기화됩니다. 앱 제공자는 이 영역에 접근할 수 없고,
iCloud에 로그인하지 않은 기기에서는 동기화가 일어나지 않습니다.
Android에서는 **기기 간 공유를 켠 경우에만** 원장이 사용자 본인의 Google 드라이브에
파일 두 개(`골고루-원장.json` — 계좌·종목, `골고루-리밸런싱.json` — 진행 중 리밸런싱)로
저장됩니다. 기본은 꺼져 있습니다. 앱이 요청하는 권한은 `drive.file` 하나이며,
이 권한으로는 **앱이 만든 그 파일만** 볼 수 있습니다 — 드라이브의 다른 파일은
존재조차 확인할 수 없습니다. 앱 제공자는 이 파일에 접근할 수 없습니다.

### 짜보기로 만든 구성안 (1.3.0부터)

아직 사지 않은 구성(계좌 이름, 담은 종목, 비중, 투자금)은 원장과 **따로** 기기에
저장됩니다. Apple 기기에서는 아이폰 · 아이패드 · 맥이 같은 목록을 보도록 사용자 본인의
iCloud에 미러링되며, 앱 제공자는 이 영역에 접근할 수 없습니다. Android에서는
기기 안에만 있습니다.

구성안을 남에게 보낼 때 만들어지는 **공유 링크는 구성을 주소의 `#` 뒤에** 담습니다.
URL 조각(fragment)은 **서버로 전송되지 않으므로** 앱 제공자의 서버에 저장되지 않고
접속 기록에도 남지 않습니다. 받은 사람이 **저장을 눌러야** 그 사람 기기에 들어갑니다.

### Google 계정 정보

**1.2.0부터 공개 앱에는 Google 로그인이 없습니다.** Google Sheets 연동을 뺐기 때문이며,
아래 내용은 1.0 버전에 해당합니다.

Google Sheets 연동을 고른 경우에만 Google 로그인을 사용합니다.
**Android 앱에는 시트 연동이 없습니다** — 둘러보기와 앱에 직접 입력만 제공하므로
아래의 시트 관련 내용은 Android에 해당하지 않습니다.

Android에서 Google 로그인이 뜨는 자리는 **기기 간 공유를 켤 때 한 번**뿐이고,
그때 요청하는 권한은 `https://www.googleapis.com/auth/drive.file` 하나입니다 —
**앱이 만든 파일만** 보고 만들고 고칩니다. 드라이브의 다른 파일에는 접근하지 않으며,
목록을 조회할 수도 없습니다. 켜지 않으면 로그인 자체가 일어나지 않습니다.

- 요청 권한: `https://www.googleapis.com/auth/spreadsheets.readonly`
  — 사용자가 지정한 스프레드시트를 **읽기만** 합니다. 수정하거나 삭제하지 않습니다.
- 사용 목적: 사용자의 `App_Data_*` 시트에서 자산 현황을 읽어 앱 화면에 표시
- 액세스 토큰은 기기의 Keychain에만 저장되며 외부로 전송되지 않습니다.
- 앱은 사용자의 Google Drive 파일 목록을 조회하지 않습니다. 사용자가 스프레드시트
  주소를 직접 입력하므로 파일 검색 권한이 필요하지 않습니다.

골고루가 Google API로부터 받은 정보의 사용과 다른 앱으로의 전송은
[Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)을
준수하며, 여기에는 제한 사용(Limited Use) 요건이 포함됩니다.

### 증권사 API 키 (3.0부터)

**3.0부터 한국투자증권 잔고를 읽어 올 수 있습니다.** 쓰지 않으면 키를 받지 않습니다.

- 앱키 · 앱시크릿 · 계좌번호 앞 8자리는 **이 기기에만** 저장됩니다 — Apple 기기는
  Keychain(꺼낼 때 Face ID 또는 기기 암호), Android는 Android Keystore로 암호화합니다.
  iCloud나 Google 드라이브로 동기화하지 않습니다.
- 잔고는 **기기에서 한국투자증권 서버로 바로** 읽습니다. 앱 제공자의 서버를 거치지
  않으며, 앱 제공자는 키 · 계좌번호 · 잔고를 받지 않습니다.
- 증권사 API는 **잔고 조회 용도로만** 사용합니다. 주문을 넣지 않습니다.
- **설정 > 증권사 연결**에서 키를 지우면 기기에서 사라집니다. Android는 앱을 삭제해도 함께
  지워지지만, Apple 기기의 Keychain은 앱을 지워도 남을 수 있으니 설정에서 먼저 지우세요.

보유 종목은 사용자가 직접 입력하거나 **증권사 앱 화면을 캡처해** 채울 수도 있습니다 —
글자 인식은 기기 안에서만 돌아가고 캡처 이미지는 어디로도 나가지 않습니다.

### 익명 사용 통계 (3.0부터)

어느 화면을 많이 쓰고 어디서 막히는지 알기 위해, 앱은 **익명 사용 기록**을 앱 제공자의
서버(Cloudflare Workers · D1)로 보냅니다. 외부 분석 SDK는 쓰지 않습니다.

| 보내는 것 | 보내지 않는 것 |
| --- | --- |
| 앱이 처음 실행될 때 만든 무작위 설치 ID(서버에는 해시값으로만 저장), 플랫폼, 앱 버전 | 이름, 이메일, 광고 식별자, 기기 식별자 |
| 연 화면 · 누른 기능의 이름과 결과(예: `tab.view` · `briefing.digest` · 성공/실패), 개수 | 금액, 종목, 수량, 계좌 이름 · 번호, 입력한 글자 |

- **설정에서 「사용 통계 보내기」를 끄면** 그때부터 보내지 않고, 아직 보내지 않은 기록도 버립니다.
- 서버는 형식에 맞지 않는 값(긴 글자, 숫자가 아닌 금액 등)을 받지 않고 버립니다.
- 기록은 **1년** 보관한 뒤 자동으로 지웁니다.
- 설치 ID는 앱을 지우면 사라지고, 다시 설치하면 새 ID가 만들어집니다 — 이전 기록과 이어지지 않습니다.

## 외부로 전송되는 정보

앱은 시세·뉴스를 위해 자체 서버리스 함수(Cloudflare Workers)를 사용합니다.
전송되는 내용은 아래로 한정됩니다.

| 기능 | 전송하는 것 | 전송하지 않는 것 |
| --- | --- | --- |
| 시세·차트 | 종목 심볼 | 보유 수량, 금액, 계좌 |
| 시장지표 | 지표 코드만 | 자산 정보 일체 |
| 뉴스·리포트 | 종목명, 검색 키워드 | 보유 수량, 금액, 계좌 |
| ETF 찾기·비교 (1.3.0) | 검색어, 종목 심볼 | 투자금, 비중, 보유 자산 |
| 아침 브리핑 (3.0) | 요약할 기사의 제목 · 주소 · 짧은 발췌, 보유 상위 종목 이름, 설치 ID | 보유 수량, 금액, 계좌 |
| 사용 통계 (3.0) | 위 「익명 사용 통계」 표의 항목 | 금액, 종목, 계좌, 입력한 글자 |

**금액 정보는 앱 제공자의 서버로 전송되지 않습니다.** 위 표에서 보듯 앱이 외부로
보내는 것은 종목 심볼 · 종목 이름 · 검색어 · 기사 정보뿐이고, 총자산·평가액·계좌 잔고 같은 금액은 포함되지
않습니다. 자산 금액·환산·배분 계산은 모두 기기 안에서 수행합니다.

**예외는 사용자 본인의 저장 공간입니다.** "앱에 직접 입력"으로 넣은 원장은
같은 계정의 기기끼리 함께 보기 위해 Apple 기기는 **본인 iCloud**로, Android는
**기기 간 공유를 켠 경우 본인 Google 드라이브**로 동기화됩니다. 두 곳 모두
사용자의 계정에 속하며 **앱 제공자는 접근할 수 없습니다.** iCloud에 로그인하지
않았거나 Android에서 기기 간 공유를 켜지 않았다면 동기화는 일어나지 않습니다.

**자산 정보는 외부 AI(LLM)로 보내지 않습니다.** 자산 진단·목표 제안·리밸런싱 계산은
전부 앱 안의 규칙 기반 로직으로 이뤄집니다.

뉴스는 Google 뉴스에서 앱이 직접 받아옵니다. **3.0의 아침 브리핑**만 AI를 씁니다 —
보유 종목 뉴스 · 리포트를 3줄로 줄이기 위해 기사 제목 · 주소 · 짧은 발췌를 앱 제공자의
서버로 보내고, 서버는 Cloudflare Workers AI로 요약합니다. 전체 요약을 만들 때는 보유 상위
종목의 **이름**이 함께 갑니다(수량 · 금액은 가지 않습니다).

- 요청에 담긴 종목 이름과 기사 주소는 요약을 만든 뒤 **저장하지 않습니다.**
- 만들어진 **기사 요약**은 같은 기사를 다른 사용자가 다시 요약하지 않도록 기사 주소의
  해시값과 함께 **30일** 저장해 공유합니다 — 누가 요청했는지는 남기지 않습니다.
- 무료 사용 한도를 세기 위해 **설치 ID의 해시값 · 날짜 · 요청 횟수**를 **7일** 보관합니다.

**화면 캡처로 종목을 가져올 때도 이미지는 전송되지 않습니다.** 붙여넣은 캡처에서
글자를 읽는 일은 기기 안의 운영체제 기능(Apple Vision)으로 이뤄집니다.
이미지는 읽는 즉시 사라지며 저장하지 않습니다.

## 보관과 삭제

- 기기 내부에 저장되는 데이터는 앱 전용 영역에 있어 다른 앱이 읽을 수 없습니다.
  Apple 기기는 파일 보호 속성이 적용되어 기기가 잠긴 상태에서는 읽을 수 없고,
  Android는 앱 전용 저장소에 두고 기기 백업에서 제외합니다.
- 설정에서 로컬 캐시와 입력한 원장을 삭제할 수 있습니다.
- 서버에 남는 것은 익명 사용 기록(1년), 사용 한도 횟수(7일), 기사 요약(30일)뿐이며
  기간이 지나면 매일 자동으로 지웁니다. 설치 ID는 해시값으로만 저장되어 특정 개인을
  알아볼 수 없습니다.
- 앱을 삭제하면 기기에 저장된 모든 데이터가 함께 삭제됩니다.
- Google Sheets 연동(Apple 기기 전용)을 해제하면 저장된 토큰이 Keychain에서 제거됩니다.
  시트 자체는 사용자 소유이므로 앱이 삭제하지 않습니다.
- [Google 계정 권한 페이지](https://myaccount.google.com/permissions)에서 언제든
  앱의 접근 권한을 철회할 수 있습니다.

## 제3자 제공

앱 제공자는 사용자의 자산 정보나 Google 계정 정보를 제3자에게 판매하거나 제공하지 않습니다.
광고 식별자를 수집하지 않으며, 분석 SDK를 탑재하지 않습니다. 3.0의 익명 사용 통계와
브리핑 요약은 앱 제공자가 운영하는 서버(Cloudflare)에서만 처리합니다 — Cloudflare는
요청을 처리하는 과정에서 IP 주소를 보게 되지만, 앱 제공자는 이를 저장하지 않습니다.

## 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

## 투자 관련 고지

앱이 제공하는 분석과 제안은 참고 자료일 뿐 투자 권유나 자문이 아닙니다.
모든 투자 판단과 그 결과에 대한 책임은 사용자 본인에게 있습니다.
