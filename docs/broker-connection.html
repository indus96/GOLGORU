증권사 연결

설정 → 증권사 연결에서 여러 증권사 연동을 한 곳에서 관리합니다.

연결 절차 (공통)

  1. 키 저장 — 증권사에서 발급한 API 키를 입력하면 기기 Keychain에 생체인증(Face ID/Touch ID) 보호로 저장됩니다. 서버에 올라가지 않습니다.
  2. 연결 확인 — 실제 API 호출로 키가 유효한지 즉시 테스트합니다.
  3. 연결 확인을 통과해야 목록에 연결됨으로 표시됩니다. 키를 새로 저장하거나 삭제하면 다시 확인 전 상태로 돌아갑니다.

업비트·바이낸스 연결 확인은 키에 등록된 IP에서만 성공합니다. 한 시트 계좌에 업비트·바이낸스가 함께 연동돼 있으면, 한쪽 동기화가 다른 거래소의 보유 코인을 0으로 밀지 않도록 서로의 보유 종목을 보호합니다.

시트 계좌와 일치시키기

  1. 계좌 탐색 (한투) — 한투는 앱키 하나로 같은 종합계좌의 상품코드 계좌들 (위탁 01 · 연금저축 22 · 퇴직연금 29 …)을 전부 조회할 수 있습니다. "계좌 탐색해 연동"을 누르면 상품코드를 순회해 존재하는 계좌를 모두 나열합니다.
  2. 연결 또는 추가 — 발견된 계좌마다 기존 시트 계좌 블록과 종목·수량 유사도를 계산해 "'○○' 계좌와 연결 (일치 87%)"처럼 추천합니다. 추천을 탭해 연결하거나, "새 계좌 블록으로 추가"로 시트에 새 블록을 만듭니다. 최종 확정은 항상 사용자가 합니다.
  3. 계좌 동기화 — 자산순위 탭의 계좌 뱃지로 들어가면 연동된 계좌(상품코드)별로 브로커 잔고와 시트의 차이를 보여주고, 승인하면 시트를 갱신합니다 (덮어쓰기 · 신규 행 삽입 · 미반영 마킹).

업비트는 키당 계좌가 하나라 블록명 입력 방식의 단일 연동을 사용합니다.

모의투자 계좌의 처리

모의투자 연동 계좌는 대시보드 자산 계산(총자산·현금·카테고리·배분 차이 카드)에서 제외됩니다. 리밸런싱·주문 검증용 계좌가 실제 자산에 섞이지 않게 하기 위함입니다.
