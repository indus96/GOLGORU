# 시작하기

골고루는 자산 데이터를 어디에 둘지 세 가지 중에서 고르게 합니다.
처음 실행할 때 고르고, 나중에 설정에서 언제든 바꿀 수 있습니다.

| 방식 | 이런 분께 | 준비물 |
| --- | --- | --- |
| 둘러보기 | 먼저 화면만 보고 싶은 분 | 없음 |
| 앱에 직접 입력 | 스프레드시트를 쓰지 않는 분 | 없음 |
| Google Sheets 연동 | 이미 시트로 자산을 관리하는 분 | Google 계정 |

## 둘러보기

로그인도 입력도 없이 예시 자산으로 모든 화면을 볼 수 있습니다.
대시보드, 자산순위, 자산배분, 구성 분석, 뉴스, AI 점검이 전부 동작합니다.

여기 있는 숫자는 실제 자산이 아닙니다. 마음에 들면 설정에서 다른 방식으로 바꾸세요.

## 앱에 직접 입력

계좌와 보유 종목을 앱 안에서 관리합니다. 데이터는 이 기기에만 저장됩니다.

1. 설정 > 데이터 소스에서 시작 방식을 **앱에 직접 입력**으로 바꿉니다.
2. 같은 화면의 **계좌·종목 편집**을 엽니다.
3. 계좌를 추가합니다. (예: 주식계좌, 연금계좌)
4. 계좌마다 보유 종목을 추가합니다 — 종목명, 심볼, 수량, 평균 단가.
5. 계좌의 현금 잔액을 입력합니다.
6. 계좌별 **목표 비중**을 설정합니다. 합계가 100%가 되어야 저장됩니다.

시세는 심볼로 자동으로 붙습니다. 평가액·수익률·비중은 앱이 계산하므로 입력하지 않습니다.

심볼을 비워두면 시세가 붙지 않고 입력한 평단으로만 계산합니다.
시세가 아직 오지 않은 종목은 평가액이 0이 아니라 원가(수량 × 평단)로 표시됩니다.

### 증권사에서 자동으로 채우기

종목을 하나씩 넣는 대신, 증권사 API 키를 연결하면 잔고를 읽어 계좌를 채울 수 있습니다.

1. 설정 > 증권사 연결에서 키를 등록하고 연결을 확인합니다.
2. 계좌·종목 편집에서 해당 계좌의 **증권사에서 가져오기**를 누릅니다.
3. 보유 종목과 예수금이 증권사 잔고에 맞춰집니다.

증권사에 없어진 종목은 수량 0으로 남고, 새로 생긴 종목은 자동으로 추가됩니다.

이 기능은 **잔고를 읽어오기만** 합니다. 앱이 주문을 넣지 않습니다.

## Google Sheets 연동

내 스프레드시트를 원장으로 씁니다. 앱은 시트를 **읽기만** 합니다.

1. 아래 템플릿을 엽니다.

   **[골고루 App_Data 템플릿 사본 만들기](TEMPLATE_URL_PLACEHOLDER)**

2. 내 Google Drive에 사본이 만들어집니다.
3. 사본에서 자산 정보를 채웁니다. 각 시트의 첫 행(머리글)은 바꾸지 마세요.
4. 브라우저 주소창에서 스프레드시트 ID를 복사합니다.

   `https://docs.google.com/spreadsheets/d/` **이 부분이 ID** `/edit`

5. 앱 설정 > 데이터 소스에서 시작 방식을 **Google Sheets 연동**으로 바꾸고 ID를 넣습니다.
6. Google 로그인 후 **시트 새로고침**을 누릅니다.

### 시트 구조

템플릿에는 네 개의 시트가 들어 있습니다.

| 시트 | 내용 |
| --- | --- |
| `App_Data_Assets` | 계좌별 보유 종목과 현금 |
| `App_Data_Allocation` | 자산배분 목표와 실제 비중 |
| `App_Data_Watchlist` | 관심 종목 |
| `App_Data_Events` | 직접 입력한 투자 이벤트 |

이미 다른 시트로 자산을 관리하고 있다면 `IMPORTRANGE`나 수식으로
`App_Data_*` 시트를 채우면 됩니다. 원본 시트는 그대로 두고,
앱은 정규화된 `App_Data_*`만 읽습니다.

### 값을 고치려면

앱은 시트를 읽기만 하므로, 목표 비중이나 보유 수량은 **시트에서 직접 수정**한 뒤
앱에서 새로고침하세요.

앱 안에서 고치고 싶다면 **앱에 직접 입력** 방식을 쓰면 됩니다.

## 방식을 바꾸면

설정에서 언제든 바꿀 수 있습니다.

각 방식의 데이터는 따로 보관되므로, 시트 연동으로 바꿨다가 다시 직접 입력으로
돌아와도 입력해둔 내용이 남아 있습니다.
