# 증권사 연결

설정 → **증권사 연결**에서 여러 증권사 연동을 한 곳에서 관리합니다.

![증권사 연결 2단계](../images/broker-connection.svg)

## 연결 절차 (공통)

1. **키 저장** — 증권사에서 발급한 API 키를 입력하면 기기 Keychain에
   생체인증(Face ID/Touch ID) 보호로 저장됩니다. 서버에 올라가지 않습니다.
2. **연결 확인** — 실제 API 호출로 키가 유효한지 즉시 테스트합니다.
3. 연결 확인을 통과해야 목록에 **연결됨**으로 표시됩니다.
   키를 새로 저장하거나 삭제하면 다시 확인 전 상태로 돌아갑니다.

| 상태 | 의미 |
| --- | --- |
| 미설정 | 키 없음 |
| 키 저장됨 · 연결 확인 필요 | 키는 있지만 연결 테스트 미통과 |
| 연결됨 | 연결 확인 성공 |

## 지원 증권사

| 증권사 | 연결 확인 방식 | 주문 |
| --- | --- | --- |
| 한국투자증권 · 모의투자 | 모의 도메인 토큰 발급 | ✅ 리밸런싱·직접 주문 |
| 한국투자증권 · 실전 | 실전 도메인 토큰 발급 | 🔜 실전 전환 단계 |
| 토스증권 | OAuth2 토큰 발급 | 🔜 준비 중 |
| 업비트 | 계좌 조회 (JWT 서명) | 🔜 고정 IP 프록시 구성 후 |

업비트 연결 확인은 키에 등록된 IP에서만 성공합니다.

## 시트 계좌와 일치시키기

1. **시트 계좌 연동** — 증권사 상세 화면에서 시트의 계좌 블록명과 연결합니다.
   같은 이름 블록이 있으면 연동만 하고, 없으면 브로커 잔고로 블록을 새로 만듭니다.
2. **계좌 동기화** — 자산순위 탭의 계좌 뱃지로 들어가면 브로커 잔고와 시트의 차이를
   보여주고, 승인하면 시트를 갱신합니다(덮어쓰기 · 신규 행 삽입 · 미반영 마킹).

## 모의투자 계좌의 처리

모의투자 연동 계좌는 **대시보드 자산 계산(총자산·현금·카테고리·배분 차이 카드)에서
제외**됩니다. 리밸런싱·주문 검증용 계좌가 실제 자산에 섞이지 않게 하기 위함입니다.
