# 자산순위

계좌별·자산군별·개별 종목별로 자산을 정렬해 보는 화면입니다.

![자산순위 구성](../images/asset-ranking.svg)

## 사용 순서

1. 상단 탭에서 **계좌별 / 자산군별 / 항목별** 보기를 고릅니다.
2. 정렬 기준(금액 · 비중 · 수익률 · 이름)을 선택합니다.
3. 종목을 탭하면 상세 차트가 열립니다.

## 동작 방식

- **합산 규칙** — 같은 종목은 계좌를 넘어 합산하고, 현금성 자산도 하나로 합산합니다.
- **실시간 시세** — 포그라운드에서 보유 종목 시세를 1초 간격으로 자동 갱신합니다.
  평가액·비중은 즉시 재계산되지만 시트 원장의 평단·수량은 바뀌지 않습니다.
- **차트 소스 자동 선택** — 한국 상장 코드·거래소 접두사는 Yahoo Finance(.KS/.KQ 폴백),
  영문 티커는 업비트 KRW 마켓(코인), 펀드 표준코드(K+11자)는 KOFIA 기준가.
- **USD 자산** — 원본 달러 평가액, 적용 환율, 앱 계산 원화액을 함께 표시합니다.
  환율이 아직 없으면 0으로 잡는 대신 안전한 상태 표시로 알려줍니다.
- **브로커 연동 계좌** — 계좌에 브로커 뱃지가 붙고, 탭하면 계좌 동기화 화면으로 이동합니다.
