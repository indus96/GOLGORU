# 데이터와 보안

## 데이터 구조

앱은 사용자의 Google Sheets에서 정규화된 `App_Data_*` 탭만 읽습니다.

```text
기존 원본 시트 (가계부·포트폴리오 등)
  → Google Sheets 수식 / IMPORTRANGE
  → App_Data_Assets · App_Data_Allocation · App_Data_Watchlist · App_Data_Events
  → 앱이 읽고 기기 안에서 계산
```

- `App_Data_*` 탭 생성은 제공되는 Apps Script로 자동화됩니다.
- 체결 기록·계좌 연동 정보는 별도 탭에 저장돼 기기 간 공유됩니다.

## 보안 장치

| 장치 | 내용 |
| --- | --- |
| Google 로그인 | Sheets 읽기 권한 범위. 쓰기는 사용자가 승인한 흐름에서만 |
| Keychain | 증권사 자격증명은 생체인증 보호로 기기에만 저장 |
| 앱 잠금 | 기기 소유자 인증으로 잠금 해제, 백그라운드 복귀 시 재잠금 |
| 로컬 캐시 보호 | 스냅샷 캐시에 파일 보호 속성 적용, 설정에서 삭제 가능 |
| 외부 전송 최소화 | 자산 데이터는 외부 서버로 전송하지 않음. AI 점검은 요약만, 뉴스·재무제표·배당 조회는 종목 식별자만 (보유 수량·금액 미전송) |
| 로그 마스킹 | 토큰·계좌번호는 로그와 화면에 노출하지 않음 |

## 장애 대응

- 시트·뉴스·시장지표 로드가 실패하면 마지막 정상 캐시로 폴백합니다.
- 시장지표는 일부 지표만 실패해도 성공한 지표는 갱신하고 실패분은 이전 값을 유지합니다.
