시작 방식에 따라 저장 위치가 다릅니다. 어느 쪽이든 앱 제공자 서버에는 저장되지 않습니다.

Google Sheets 연동사용자 본인의 스프레드시트iPhone · iPad · Mac

앱에 직접 입력한 데이터

계좌·보유 종목·현금·목표 비중이 기기 내부에 JSON으로 저장됩니다. 저장 위치는 다른 앱이 읽을 수 없는 앱 전용 영역입니다.

Apple 기기에서는 아이폰·아이패드가 같은 원장을 보도록 사용자 본인의 iCloud에도 동기화됩니다. 이 영역은 사용자의 Apple 계정에 속하고 앱 제공자는 접근할 수 없습니다. iCloud에 로그인하지 않은 기기에서는 동기화가 일어나지 않으며, Android 앱에는 이 동기화가 없습니다.

기기보호 방식
iPhone · iPad · Mac앱 샌드박스 + 파일 보호 속성 — 기기가 잠긴 상태에서는 읽을 수 없습니다
Android앱 전용 저장소 — 다른 앱이 접근할 수 없고, 기기 백업에도 포함되지 않습니다

이 데이터는 어떤 서버로도 전송되지 않습니다. 설정에서 삭제할 수 있고, 앱을 삭제하면 함께 사라집니다.

Google Sheets 연동 (iPhone · iPad · Mac)

Android 앱에는 Google 로그인과 시트 연동이 없습니다 — 둘러보기와 앱에 직접 입력 두 가지로 씁니다.

앱은 사용자의 스프레드시트에서 정규화된 App_Data_* 탭만 읽습니다.

기존 원본 시트 (가계부·포트폴리오 등)
  → Google Sheets 수식 / IMPORTRANGE
  → App_Data_Assets · App_Data_Allocation · App_Data_Watchlist · App_Data_Events
  → 앱이 읽고 기기 안에서 계산
  • App_Data_* 탭은 제공되는 템플릿 사본으로 한 번에 만듭니다.
  • 요청 권한은 spreadsheets.readonly 하나입니다 — 앱이 시트를 고치거나 지우지 않습니다.
  • Google Drive 파일 목록은 조회하지 않습니다. 사용자가 스프레드시트 주소를 직접 넣습니다.

보안 장치

장치내용
Google 로그인spreadsheets.readonly — 읽기 전용. 쓰기 권한을 요청하지 않음 (Apple 기기 전용)
자격증명 보관증권사 API 키는 기기에만 — Apple 기기는 Keychain, Android는 기기 보안 칩(Keystore) 키로 암호화해 앱 전용 저장소에. 잔고 조회에만 사용
앱 잠금생체인증(지문·얼굴)으로 잠금 해제하고, 없으면 기기 잠금(PIN·패턴·비밀번호)으로 대신합니다. 백그라운드에 다녀오면 다시 잠깁니다
로컬 캐시 보호스냅샷 캐시도 앱 전용 영역에 저장, 설정에서 삭제 가능
외부 전송 최소화뉴스·시세·재무제표·배당 조회는 종목 식별자만 전송 — 보유 수량·금액·계좌는 보내지 않습니다
외부 AI에 자산 정보 미전송자산 진단·목표 제안·리밸런싱 계산은 전부 앱 안의 규칙 기반 로직입니다. AI가 쓰이는 곳은 뉴스 번역 하나뿐이고, 전달되는 것은 기사 제목·요약뿐입니다
로그 마스킹토큰·계좌번호는 로그와 화면에 노출하지 않음

장애 대응

  • 시트·뉴스·시장지표 로드가 실패하면 마지막 정상 캐시로 폴백합니다.
  • 시장지표는 일부 지표만 실패해도 성공한 지표는 갱신하고 실패분은 이전 값을 유지합니다.
