# GOLGORU — 골고루

> **내 자산을 골고루.**
>
> iPhone · iPad · Mac에서 쓰는 개인 자산관리 앱 — 내 Google Sheets를 원장으로,
> 자산 현황부터 증권사 리밸런싱 주문까지.

이름 그대로, 흩어진 계좌를 한눈에 모으고 목표 배분에 맞춰 자산을 **골고루** 나누는 앱입니다.

본인의 Google Sheets를 자산 원장으로 삼아 자산 현황을 한눈에 보여주고,
목표 자산배분과의 차이를 계산해 증권사 API로 리밸런싱 주문까지 실행합니다.
데이터 원본은 항상 사용자의 시트에 있고, 앱은 이를 읽고 계산하고 **승인된 주문만**
대신 넣는 도구입니다.

![데이터 흐름](images/data-flow.svg)

## 핵심 원칙

- **시트가 원장** — 앱이 데이터를 소유하지 않습니다. 시트를 지우지 않는 한 데이터는 사용자 것입니다.
- **기기 안 계산** — 자산 금액·환산·배분 계산은 모두 앱 내부에서 수행합니다. 자산 데이터가 외부 서버로 전송되지 않습니다.
- **승인 기반 주문** — 리밸런싱은 계획을 먼저 보여주고, 사용자가 확인한 뒤에만 주문을 넣습니다.

## 지원 환경

- iPhone / iPad / Mac (SwiftUI 공용 코드베이스)
- Google 계정과 정규화된 `App_Data_*` 시트 (생성 스크립트 제공)
- 증권사 연결: 한국투자증권(모의·실전), 토스증권, 업비트 — 키 저장과 연결 확인 지원

## 현재 상태

한국투자증권 **모의투자**로 리밸런싱·직접 주문·계좌 동기화 실사용 검증을 마치고,
실전 계좌 전환을 준비하는 단계입니다.

- ✅ 자산 현황·순위·배분 차이·뉴스·AI 점검
- ✅ 자산 구성 분석 (건강점수·인사이트·배당·자산 추정·목표·개선 제안)
- ✅ 모의투자 리밸런싱 (분할 회차·예약·휴장일 처리·실시간 체결 확인)
- ✅ 증권사 4곳 키 연결·연결 테스트
- 🔜 실전 계좌 주문 전환, 업비트 실주문, 일반 공개
